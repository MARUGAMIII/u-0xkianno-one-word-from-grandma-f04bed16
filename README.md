One original word for make.fun's "One Word From Grandma" bounty — the single word a grandma would text about AI:

> Frankenstein

A grandma's classic shorthand for science gone too far: warm, a little baffled, and funny in a single word, with no caption needed. She has watched scientists play God on the telly for sixty years; the moment a grandchild shows her a machine that talks back, one word leaves her phone.

The entry program writes that single word to `/output/entry.txt` — one word, 12 characters, UTF-8 — and checks it against the gate itself (1–30 characters, one word, letters only) before writing.

## Run it

```sh
python3 main.py
```
